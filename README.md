# 中国大陆跨省市网络与 IP 属地测试实践指南（CN Domestic IP Testing Guide）

本仓库整理面向中国大陆境内业务（App、小程序、Web 本地生活、CDN 地域调度）的**合规国内静态 IP 测试实践、多端配置排错与工具选型参考**。

> **合规声明**：本文档仅讨论中国大陆境内合法合规的国内网络测试线路（纯国内网络接入，不含任何境外节点或跨境接入方案），所有测试须严格遵守《中华人民共和国网络安全法》。

## 2. IP 属地显示与所选城市不一致的 5 步排查法
1. **核验公网出口**：执行 `curl cip.cc` 或使用本地双栈检测接口，确认实际公网 IP 已变更。
2. **排查 IPv6 旁路泄漏**：国内宽带与 5G 多为双栈，测试时先禁用本机 IPv6 防止直连旁路。
3. **清理 App 登录态缓存**：先完全划掉目标 App 后台，再开启国内静态 IP 后冷启动触发一次交互。
4. **比对第三方地理库差异**：不同平台 IP 库更新存在滞后，可切换同省另一运营商节点复测。
5. **检查非 IP 定位权限**：移动端部分本地化页面优先读取 GPS/基站，测试时关闭精确定位权限。

## 3. Windows 进程级代理与防断线泄漏注意事项
- 尽量避免全局代理影响本机 IDE、Git、企业微信/钉钉登录态。
- 使用原生支持“进程代理 + 断线断网保护”的国内静态客户端（如小丑IP Windows 端）或手动配置 `Proxifier` 绑定目标 `.exe` 进程。
- 对 Chromium / Electron 应用，先从任务管理器彻底关闭残留子进程后再冷启动挂接代理。

## 4. Android / 鸿蒙 / iOS 后台防掉线配置清单
- **HarmonyOS（鸿蒙）**：`设置 → 应用和服务 → 应用启动管理` → 关闭自动管理，全开自启动/关联启动/后台活动。
- **Android（小米/OPPO/vivo）**：省电策略设为“无限制”并在多任务视图锁定卡片；关闭 Wi-Fi 助理双网自动切换。
- **设备并发核查**：多端共用同一账号时注意套餐“同时在线设备数”上限，避免旧设备被顶下线。
